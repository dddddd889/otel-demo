Context 与传播速查表

AsyncLocalStorageNode.js 提供的异步调用链本地存储。
OTel Context不可变键值容器，可携带 Active Span、Baggage 等。
Context Manager让当前 Context 跟随 Promise、Timer 和回调。
context.active()读取当前 Context；没有激活范围时返回根 Context。
context.with(ctx, fn)仅在 fn 及其派生异步工作中激活 ctx。
startSpan创建 Span，但不会主动激活它。
startActiveSpan创建并在 callback 中激活 Span。
Propagation跨进程 inject/extract traceparent、baggage。

边界口诀

进程内：Context Manager
跨进程：Propagator + Carrier
创建 Span：startSpan
创建并激活：startActiveSpan
结束 Span：始终显式 span.end()
